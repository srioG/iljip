## 8. 일집-dist 바꾸기 전 — 재사용장치 egg 해제 (5분) — 통합 점검

재사용장치는 메일로 온 egg·alz 첨부를 `D:\Python\일집-dist\Iljip.exe --extract-to <첨부> <임시폴더>` 로 풉니다(창 없이).
일집-dist 를 새 판으로 바꾸면 **다음 날부터 이 해제가 새 판으로** 바뀌므로, 바꾸기 전에 진짜 egg 몇 개를 새 판으로 풀어 봅니다.
새 판은 egg/alz 의 크기·CRC 를 직접 확인합니다(예전 판은 확인 안 함). 진짜 알집 파일에서 이 확인이 어긋나면 멀쩡한 egg 도 실패로 끝나고
재사용장치가 반디집으로 다시 풉니다(반디집을 지운 PC 라면 해제 실패) — 그래서 이 절이 필요합니다.

1. 최근에 받은 **진짜 egg 첨부 2~3개**(가능하면 한글 이름·하위 폴더가 든 것, 알집으로 만든 것)를 `일집점검` 폴더에 **복사**합니다(원본은 그대로).
2. PowerShell 에 아래를 붙여 넣습니다(첫 줄의 파일 이름만 바꾸세요). 창은 뜨지 않고 끝에 숫자가 나옵니다.
   ```powershell
   $egg = "$env:USERPROFILE\Desktop\일집점검\받은첨부.egg"
   $새판 = "D:\Python\일집-build\dotnet\Iljip\bin\Release\net8.0-windows\Iljip.exe"
   $결과 = "$env:USERPROFILE\Desktop\일집점검\새판_결과"
   (Start-Process $새판 -ArgumentList '--extract-to', "`"$egg`"", "`"$결과`"" -Wait -PassThru).ExitCode
   ```
3. 같은 파일을 예전 판으로도 풀어 비교합니다(예전 판은 실행만 하고 고치지 않습니다).
   ```powershell
   $예전판 = "D:\Python\일집-dist\Iljip.exe"
   $결과2 = "$env:USERPROFILE\Desktop\일집점검\예전판_결과"
   (Start-Process $예전판 -ArgumentList '--extract-to', "`"$egg`"", "`"$결과2`"" -Wait -PassThru).ExitCode
   ```

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | 새 판 숫자 | **0**. `새판_결과` 폴더에 파일이 다 있고 한글 이름이 안 깨짐. 1 이 나오면 그 파일 이름을 적어 두기(바꾸기 전에 알려 주세요) |
| □ | 두 결과 폴더 비교(파일 개수·크기·열어 보기) | 새 판이 예전 판과 같거나 더 많이 풀림(예전 판은 0바이트 파일·폴더가 든 egg 에서 실패하거나 alz 한글 이름이 깨졌음) |
| □ | 알집 **암호** egg 가 있으면 새 판으로(위 2번) | 숫자 **1**(창 없이는 암호를 넣을 수 없음 — 정상). 재사용장치는 이때 반디집으로 넘김(예전과 같음) |
| □ | (IJ3-03) **메일에서 받아 저장한** egg 첨부(아웃룩에서 저장 — '인터넷에서 받은 파일' 표시가 붙은 것)로 위 2번을 한 뒤 PowerShell: `Get-Item "$env:USERPROFILE\Desktop\일집점검\받은첨부.egg" -Stream *` → `Get-ChildItem "$결과" -Recurse -File \| Get-Item -Stream Zone.Identifier -ErrorAction SilentlyContinue` | 첫 줄에 `Zone.Identifier` 가 보이면 받은 첨부에 표시가 있는 것. 둘째 줄은 **아무것도 안 나와야** 정상(창 없이 풀기는 표시를 붙이지 않음 — 재사용장치가 엑셀로 자동 처리하는 파일이 '제한된 보기'로 막히지 않게). 무언가 나오면 적어 두기(재배포 보류) |
| □ | (바꾼 다음 날) 재사용장치 로그 | '(Iljip으로 .egg 해제)' 다음에 '(Iljip 해제 실패: … → Bandizip 폴백)' 이 예전보다 늘지 않았는지. 늘었으면 그 줄을 적어 두기 |

> 바꾸는 방법·되돌리는 방법은 `D:\Python\일집\HANDOFF.md` '일집-dist 재배포' 절에 있습니다. 재사용장치가 도는 시간에는 바꾸지 마세요.

### 재배포 뒤 1~2주 지켜보기 — 진짜 egg (3차 통합 점검)

**왜**: 이 PC 에는 알집으로 만든 **진짜 egg 견본이 없어서** 자동 시험은 직접 만든 egg 로만 했습니다. 새 판은 egg 를 풀면서 크기·CRC 를 직접 확인하는데,
진짜 알집 파일에서 이 확인이 어긋나면 일집이 실패하고 재사용장치가 **반디집으로 다시 풉니다**(반디집이 있으면 결과는 같음 — 그래서 아래 기간에는 반디집을 지우지 않습니다).
메일로 egg 첨부가 오는 일은 드물어서(6월 기록: 2주에 1~2개) 한 번 확인으로는 부족하고, 실제 첨부가 몇 개 지나갈 때까지 지켜봅니다.

1. 일집-dist 를 바꾼 날부터 **1~2주(egg 첨부가 5~10개 지나갈 때까지) 반디집을 지우지 말고 그대로** 둡니다.
2. 재사용장치를 돌린 날은 화면 로그에서 '(Iljip으로 .egg 해제)' 바로 다음 줄을 봅니다 — '(Iljip 해제 실패: … → Bandizip 폴백)' 이면 그 첨부 이름을 적어 둡니다.
   (수동 모드의 화면 로그는 창을 닫으면 사라집니다. 16시 자동 모드면 `D:\Python\재사용장치\System_code\logs\batch_날짜.log` 에 남습니다.)
3. 화면 로그를 놓쳐도 되게, **일주일에 한 번** 아래를 PowerShell 에 붙여 넣습니다(일집이 창 없이 풀다 실패한 첨부마다 경로와 이유가 남아 있음 — 3차 통합 점검에서 넣음).
   ```powershell
   Select-String -Path "$env:LOCALAPPDATA\Iljip\logs\error-*.log" -Pattern "Headless extract failed: " -Context 0,1 |
     Where-Object { $_.Line -notmatch 'IljipTests' } |
     ForEach-Object { $_.Filename; $_.Line; $_.Context.PostContext }
   ```
   (`IljipTests` 가 든 줄은 개발 중 자동 시험이 남긴 것이라 뺍니다.)
4. 읽는 법: 첨부마다 두 줄 — `[날짜 시각] Headless extract failed: <첨부 경로>` 와 그 아래 이유.

| □ | 나온 이유 | 할 일 |
|---|---|---|
| □ | 아무것도 안 나옴 | 정상 — 일집이 다 풀었음 |
| □ | `암호가 걸린 압축 파일이에요…`(PasswordRequired) | 정상 — 창 없이는 암호를 못 넣어 반디집이 풂(예전과 같음) |
| □ | 그 밖의 이유(`손상`·`CRC`·`내용 확인값`·`알 수 없는 오류` 등) | **그 egg 첨부를 따로 복사해 보관**하고 반디집으로는 풀렸는지 확인 → 파일 이름·이유를 적어 알려 주기(다음 판에서 고칠 거리). 반디집은 계속 둠 |
| □ | 2주 동안 '그 밖의 이유'가 하나도 없음 | 반디집을 지울지는 그때 정함(사용자 결정 — 지우면 일집이 못 푸는 egg 는 재사용장치가 원본만 보관) |

5. 잘 찾는지 미리 보고 싶으면(선택): 진짜 egg 사본의 뒤를 잘라 일부러 깨뜨려 8절 2번 명령으로 풀어 봅니다 — 숫자 **1**, 3번 명령에 그 경로가 나오면 정상.
   ```powershell

   ```

| □ | 파일 몇 개를 모아 **압축** → 저장 창의 '파일 형식'에서 **7Z 압축 파일 (*.7z)** 고르기 | 7Z 가 ZIP 바로 아래에 있음. (7z.dll 이 막힌 PC 에서는 7Z 가 **안 보여야** 정상) |
| □ | 이어서 뜨는 옵션 창(.7z) | 수준이 **저장만·빠름·보통(권장)·최대** 네 칸. '암호 방식 (ZIP)' 칸은 **안 보임**. '7Z 옵션' 아래 **솔리드 압축(더 작게, 일부만 꺼내기는 느림)** 은 켜져 있고, **파일 이름도 암호로 숨기기** 는 암호를 넣기 전엔 회색(못 누름) → 암호를 넣으면 누를 수 있고, 암호를 지우면 체크가 풀림. 아래 안내에 "7Z 는 AES-256 으로 암호를 걸어요. 한글 암호도 반디집·7-Zip 에서 풀려요." |
| □ | 옵션 창(.7z): 한글 암호 `테스트암호` 두 칸 + **파일 이름도 암호로 숨기기** → 확인 | 한글 암호 경고 창이 **뜨지 않음**(ZIP 과 다름). 7z 가 만들어진 뒤 바로 열리며 **암호를 다시 묻지 않음**. 이어서 [압축 풀기]도 묻지 않음 |
| □ | 위 7z 를 **반디집**·**7-Zip**(있으면)으로 열기 | 열 때 암호를 묻고(파일 이름이 가려져 있음) `테스트암호` 로 목록이 보이고 풀림. 한글 이름·빈 폴더·0바이트 파일이 그대로. 7-Zip 의 '속성'에서 방법이 `LZMA2:24 7zAES` 비슷하게, 솔리드면 '솔리드 +' 표시 |
| □ | 같은 7z 를 일집으로 **새로** 열기(창을 닫았다가 더블클릭 또는 우클릭 → 일집으로 열기) | 암호 창 "파일 목록까지 암호로 잠긴 압축 파일이에요. 암호를 넣어 주세요." → 틀린 암호면 작은 경고 창 "암호가 맞지 않아요. 다시 넣어 주세요." 뒤 다시 물음 → [취소] 하면 **보던 화면 그대로**(오류 창 없음) |
| □ | 다른 압축을 보고 있는 채로 위 7z 를 열다가 암호 창 **취소** | 보던 압축·목록이 그대로 남음(상태줄만 "열기를 취소했어요"). 보던 압축을 그대로 풀 수 있음 |
| □ | 옵션 창 두 칸을 다르게(.7z) | "비밀번호가 일치하지 않아요." (ZIP 과 같음) |
| □ | 수백 MB~1GB 폴더(동영상·사진 등)를 **보통** 수준 7z 로 압축하며 **작업 관리자**(Ctrl+Shift+Esc → 세부 정보 → Iljip.exe '메모리(활성 개인 작업 집합)') 보기 | 진행 막대가 **천천히 차오름**(몇 초 만에 100% 가 되면 적어 두기 — 1차 지적). 메모리는 대략 **수백 MB 이하**(1GB 를 넘으면 적어 두기 — 1차 W1-B 는 1.7~3.4GB). '최대' 수준도 한 번(더 느리지만 메모리는 비슷) |
| □ | 위 압축을 절반쯤에서 진행 창 **취소** | **몇 초 안에** "압축 취소됨". 저장하려던 자리에 `.7z` 도, 숨긴 `.~이름….tmp` 파일도, `.일집-임시-…` 폴더도 **남지 않음**(탐색기 '숨긴 항목' 켜고 확인). 같은 이름의 예전 7z 를 덮어쓰려던 중이었다면 **예전 파일이 그대로** |
| □ | 아웃룩을 켠 채로 .pst 가 든 폴더를 **7z** 로 압축 | ZIP 과 같게 끝에 "압축을 마쳤어요. 건너뛴 파일 1개: …(다른 프로그램이 쓰고 있어요)" 안내, 7z 는 남고 열림 |
| □ | 빈 폴더가 든 폴더를 7z 로 압축 → 반디집·7-Zip 으로 열기 | 빈 폴더도 보임. 모든 폴더가 폴더로 보이고 풀면 폴더의 수정한 날짜가 원래와 같음 |
| □ | **OneDrive 동기화 폴더** 안에 7z 를 저장(수십 MB 이상) | 저장 중 숨김 `.~이름….tmp`·`.일집-임시-…` 가 잠깐 생겼다가 끝나면 사라지고 7z 하나만 남음. "다른 프로그램이 쓰고 있어요" 등이 나면 적어 두기(OneDrive·DLP 가 임시 파일을 잡은 것) |
| □ | **7-Zip**(있는 PC)에서 '파일 이름 암호화'(-mhe)로 만든 7z, **WinRAR** '파일 이름 암호화' RAR4·RAR5 를 일집으로 열기·우클릭 풀기 | 열 때 한 번 묻고(위와 같은 문구), 우클릭 풀기도 **한 번만**. 자동 테스트는 py7zr·합성 RAR 로만 확인 — 영어 오류 창이 뜨거나 두 번 물으면 적어 두기 |
| □ | 창 없이 풀기(8절 PowerShell 에서 파일만 바꿈)로 위 '파일 이름 암호화' 7z·RAR 풀기 | 창이 뜨지 않고 숫자 **1**(암호를 넣을 수 없음 — 재사용장치는 반디집으로 넘김). 결과 폴더에 아무것도 없음 |

## 11. 나눠 만들기(분할 압축) (6분) — W2-03

자동 테스트는 일집이 나눈 ZIP(`이름.z01 … 이름.zip`)·7Z(`이름.7z.001 …`)를 일집·7z.dll·**반디집 콘솔(bz.exe t)**로 다시 풀어 봤습니다
(한글 암호 ZipCrypto·영문 AES·7z 한글 암호 + 파일 이름 암호화, 목록이 조각을 넘는 2,000개, 항목 7만 개). **옵션 창 모양·Windows 탐색기·알집·진짜 메일 첨부**는 사람이 봐야 합니다.

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | 파일을 모아 **압축** → ZIP 으로 저장 → 옵션 창 | 아래쪽에 **'나누기 (메일로 보낼 때)'** 칸: 나누지 않음(처음 값)·10MB·20MB (메일 첨부용)·직접 입력 (MB). 안내에 "메일 첨부 한도보다 작게 고르세요", "Windows 탐색기로는 열리지 않아요" |
| □ | 같은 창에서 저장 형식을 **TAR**(또는 GZ)로 | '나누기' 칸이 **안 보임** |
| □ | '직접 입력 (MB)' 를 고르면 | 옆에 숫자 칸과 'MB' 가 나타남. `0.5` 를 넣고 확인 → "1MB 이상으로 넣어 주세요." 경고 뒤 창이 그대로. `숫자아님` → "나눌 크기를 숫자(MB)로 넣어 주세요." |
| □ | 30MB 넘는 폴더를 **10MB** 로 ZIP 압축 | 끝나면 안내 "N개 조각으로 나눠 만들었어요(이름.z01 … 이름.zip). 받는 사람은 모든 조각을 같은 폴더에 두고 이름.zip을 열면 돼요." + 탐색기 안내 한 줄. 저장한 곳에 `이름.z01`·`이름.z02`…·`이름.zip` 이 있고 **각 10MB 이하**(마지막만 작을 수 있음). 일집 창에 목록이 바로 보임 |
| □ | 위 조각들을 **반디집**으로 열기(`이름.zip` 더블클릭 또는 반디집에서 열기) → 풀기 | 목록이 보이고 다 풀림(한글 이름 그대로) |
| □ | 위 조각들을 **알집**(있으면)·**7-Zip**(있으면)으로 열기 | 열리고 풀림. **알집이 못 열면 적어 두기**(자동 테스트는 반디집·7z.dll 만 — 알집은 실물 확인 필요) |
| □ | 위 `이름.zip` 을 **Windows 탐색기**에서 더블클릭(기본 'ZIP 폴더') | **열리지 않거나 비어 보이는 것이 정상**(Windows 는 나뉜 ZIP 을 못 엶 — 안내 문구가 이것을 알림). 혹시 열리면 적어 두기 |
| □ | 같은 폴더를 **20MB** 로 **7Z** 압축(암호 + 파일 이름도 암호로 숨기기) | `이름.7z.001`·`.002`… 가 생기고 안내의 '열 파일'이 `이름.7z.001`. 일집 창에 목록이 바로 보이고 암호를 다시 묻지 않음. 반디집·7-Zip 으로 `.001` 을 열면 암호를 묻고 풀림 |
| □ | 같은 이름으로 **한 번 더** 나눠 압축(10MB, ZIP) | 있던 조각은 그대로 두고 새 조각이 `이름 (2).z01 … 이름 (2).zip` 로 생김(안내에도 그 이름) |
| □ | 작은 파일(1MB 안팎)을 **10MB** 로 나눠 압축 | 나누지 않고 `이름.zip` 하나만 생김(조각 안내 없음) |
| □ | 큰 폴더를 나눠 압축하다가 진행 창 **취소** | "압축 취소됨". 저장하려던 곳에 조각(.z01·.zip·.7z.001)도 숨김 폴더 `.일집-임시-…` 도 **남지 않음**(탐색기 '숨긴 항목' 켜고 확인) |
| □ | 나뉜 ZIP 조각 중 `.z02` 를 다른 폴더로 옮기고 `이름.zip` 열기 | "'이름.z02' 조각이 없어요. 나눠진 조각을 모두 같은 폴더에 두고 다시 해 주세요." (7Z 는 `.7z.002` 를 옮기고 `.001` 열기 → 같은 꼴의 문구) |
| □ | 10MB 조각 몇 개를 **회사 메일(아웃룩)에 첨부**해 자기에게 보내 보기 | 보내지고 받은 조각을 한 폴더에 저장해 반디집으로 풀림. 메일이 '첨부가 너무 큼'으로 막히면 크기와 메일 한도를 적어 두기(첨부는 보낼 때 약 1.37배 커짐 — 20MB 조각은 25MB 한도 메일에서 막힐 수 있음) |
| □ | **OneDrive 동기화 폴더** 안에 나눠 저장 | 숨김 `.일집-임시-…` 가 잠깐 생겼다가 사라지고 조각만 남음. "다른 프로그램이 쓰고 있어요" 가 나면 적어 두기(DLP·OneDrive 가 조각을 잡은 것) |

## 12. 같은 이름 창·메인 창 없는 우클릭 풀기·풀고 나서 지우기·여러 개 풀기 (8분) — W2-05

자동 테스트는 가짜 창으로 흐름(묻는 횟수·고른 대로 되는지·임시 파일이 안 남는지·휴지통에 무엇을 보냈는지·요약 내용)을 확인했습니다.
**창 모양, 메인 창이 정말 안 뜨는지, 창이 다른 창 뒤에 숨지 않는지, 진짜 휴지통·네트워크 드라이브, 여러 개를 골라 우클릭했을 때 하나로 묶이는지**는 사람이 봐야 합니다.
0절의 파일을 쓰고, 아래 '여기에 풀기'는 `일집점검` 바로 아래에 풉니다(끝나면 생긴 `일집_샘플` 폴더를 지우고 다음 줄로).

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | (일집을 끈 채로) `zip_default.zip` 우클릭 → **"zip_default"\ 에 풀기 (일집)** | **일집 메인 창은 안 뜨고** 진행 창만 화면 가운데에 잠깐 뜬 뒤, `zip_default` 폴더가 **탐색기로 열림**. 작업 표시줄에 일집이 남지 않음(끝나면 스스로 꺼짐) |
| □ | `zip_default.zip` 우클릭 → **여기에 풀기 (일집)** | 진행 창만 뜨고 풀림. **탐색기 창은 새로 안 열림**(이미 보던 폴더라서) |
| □ | 같은 메뉴(**여기에 풀기**)를 한 번 더 | **'같은 이름 파일 - 일집'** 창: "‘readme.txt’ 파일이 이미 있어요." + '있는 파일'·'새 파일'의 크기·날짜, 버튼 [덮어쓰기] [건너뛰기] [이름 바꾸기] [취소], 체크 '남은 파일도 똑같이 (남은 파일 N개)'. **[이름 바꾸기]가 기본**(Enter). 창이 탐색기 **뒤에 숨지 않음** |
| □ | 그 창에서 '남은 파일도 똑같이'를 켜고 **[건너뛰기]** | 다시 묻지 않고 끝남. 원래 파일들이 그대로(수정한 날짜 안 바뀜), `(1)` 붙은 파일 없음 |
| □ | 한 번 더 → 이번엔 '남은 파일도 똑같이' + **[덮어쓰기]** | 묻지 않고 끝남. 파일들의 수정한 날짜가 압축 안의 날짜로 바뀜. 숨김 파일 `.~…tmp` 가 **남지 않음**(탐색기 '숨긴 항목' 켜고 확인) |
| □ | 한 번 더 → **[취소]** (또는 창의 X, Esc) | 아무 창 없이 조용히 끝남(오류 창 없음). **원래 있던 파일은 그대로**, 이번에 새로 생긴 것만 없어짐 |
| □ | `일집_샘플\견적서_2026.txt` 를 메모장으로 열어 둔 채(또는 읽기 전용으로 바꾸고) 여기에 풀기 → [덮어쓰기] | 쉬운 한국어 오류 "‘견적서_2026.txt’ 파일을 덮어쓰지 못했어요. 다른 프로그램(보안 프로그램 포함)이 쓰고 있어요…" — **읽기 전용**이면(W2-11 검증 지적) "'견적서_2026.txt' 파일이 읽기 전용이라 덮어쓰지 못했어요. 탐색기에서 그 파일을 오른쪽 클릭 → [속성] → '읽기 전용'을 끄고…"(관리자 권한 질문 없음). 원래 파일 내용은 그대로 |
| □ | 일집 창 오른쪽 위 **☰ → 설정...** | '설정 - 일집' 창: '같은 이름이 있을 때' = 물어보기(처음 값)·덮어쓰기·건너뛰기 (있는 파일 그대로)·이름 바꾸기 (예: 보고서 (1).xlsx), "탐색기 우클릭으로 '이름' 폴더에 풀면 다 푼 뒤 그 폴더 열기"(켬), '다 푼 뒤 압축 파일을 휴지통으로 옮기기'(끔). [확인] 뒤 일집을 다시 켜도 그대로(설정 파일 `%LOCALAPPDATA%\Iljip\settings.json`) |
| □ | 설정에서 '이름 바꾸기'로 바꾸고 여기에 풀기 한 번 더 | 묻지 않고 `(1)` 붙은 파일이 생김(예전 동작). 확인 뒤 '물어보기'로 되돌리기 |
| □ | 설정에서 '폴더 열기'를 끄고 "이름"\ 에 풀기 | 풀리기만 하고 탐색기가 안 열림. 확인 뒤 다시 켜기 |
| □ | 설정에서 **'다 푼 뒤 압축 파일을 휴지통으로 옮기기'** 켬 → `zip_default.zip` 을 복사한 `지울것.zip` 을 "이름"\ 에 풀기 | 풀린 뒤 `지울것.zip` 이 사라지고 **휴지통에 있음**(휴지통에서 [복원] 되는지까지 확인). 확인창은 뜨지 않음 |
| □ | 같은 설정으로 `7z_split.7z.001`(조각 셋 복사본) 을 "이름"\ 에 풀기 | 풀린 뒤 `.001`·`.002`·`.003` **셋 다** 휴지통으로 |

## 13. 압축 고치기·압축 속 파일 고쳐서 다시 넣기 (10분) — W2-06

자동 테스트는 고친 압축의 목록·내용·암호 방식·한글 이름, 실패하면 원본이 그대로인지, 반디집(`bz t`)이 푸는지, 가짜 창으로 묻는 흐름과 가짜 파일 감시로 '다시 넣기'를 확인했습니다.
**도구 막대·메뉴·F2 이름 칸·창 모양, 진짜 메모장·엑셀로 저장했을 때 묻는 횟수, 일집을 닫을 때 묻기, 회사 PC 보안 프로그램(DLP)·OneDrive 폴더에서 바꿔 넣기, 큰 압축의 시간**은 사람이 봐야 합니다.

## 14. 한 화면 압축 창·각각 따로·날짜·쓸모없는 파일 빼기·원본 지우기 (15분) — W2-07(+ 검증 지적 수정 1차·2차 줄)

자동 테스트는 가짜 창의 답으로 각각 따로 만들기(ZIP·7Z·TAR 왕복·'이름 (2)'·요약), 이름의 날짜(세 모양·두 번 안 붙임), 쓸모없는 파일 빼기(기본 목록·끄기·사용자 목록),
원본 지우기(가짜 휴지통 — 시험 통과 + [옮기기]일 때만, 지우지 않는 경우들), 설정 기억(settings.json 왕복·암호 없음), 창의 보이기 규칙(VM)을 확인했습니다.
(검증 지적 2차) 압축 창·설정 창 XAML 은 띄우지 않고 만들어 보기만 했습니다(묶기 오류 0) — 실제 화면 모양은 아래 줄로 봅니다.
**창 모양·칸 순서·Tab 이동·[찾아보기] 창, 진짜 휴지통으로 옮기고 되살리기, 네트워크 드라이브·USB, 회사 PC 보안 프로그램(DLP)·OneDrive 폴더, 오피스가 만드는 `~$` 파일**은 사람이 봐야 합니다.
`일집점검\압축재료` 폴더를 만들고 그 안에 `보고서.xlsx`(엑셀에서 빈 통합 문서 저장)·`견적서 최종.txt`(메모장, 한글 한 줄)·`거래처A` 폴더(안에 메모장 파일 하나)를 둡니다.
`거래처A` 를 탐색기에서 **'큰 아이콘'으로 한 번 보면** `Thumbs.db` 가 생길 수 있고(숨김 항목 켜고 확인), `보고서.xlsx` 를 **엑셀로 열어 둔 동안** 같은 폴더에 `~$보고서.xlsx` 가 생깁니다.

> 원본이 그새 바뀌었는지는 크기와 **수정 시각**(압축하기 직전과 비교)으로 봅니다 — 내용을 바꾸면서 수정 시각까지 예전 값으로 되돌리는 프로그램이 고친 파일은 알아채지 못합니다(그래도 휴지통에서 되살릴 수 있음).
> 휴지통으로 옮기는 중에 진행 창 [취소]를 누르면 아직 보내기 전일 때만 멈춥니다(보내기 시작한 뒤에는 끝까지 — 휴지통에서 되살릴 수 있음).
> 같은 이름 질문의 [새 이름으로 만들기] 이름은 창에서 미리 보인 것이고, 그 사이 같은 이름이 또 생기면 `(3)` 처럼 다음 번호로 만듭니다.
> (검증 지적 2차) 일집을 두 개 띄워 **같은 순간 같은 곳에 같은 이름으로** 압축하면 뒤의 것이 앞의 것을 덮을 수 있습니다(예전 저장 창 때부터 같은 방식 — 원본은 지우기 직전에 압축 목록과 다시 맞춰 보므로 사라지지 않음).
> 속이 TAR 가 아닌 파일에 이름만 `.tar` 를 붙여 GZ·BZ2 로 압축하면 만들기·시험은 되지만, 만든 `.tar.gz` 를 일집으로 열면 TAR 로 펼치려 해 내용이 제대로 보이지 않을 수 있습니다(반디집·7-Zip 으로는 원래 파일이 풀림).

> 맥(NFD) 이름은 풀 때 NFC(붙은 글자)로 바꿔 씁니다 — 압축 안에 NFC·NFD 로만 다른 같은 이름이 둘 있으면 둘째는 '이름 (1)' 로 풀립니다.
> (검증 지적 1차) 그런 두 파일은 목록에 같은 이름 두 줄로 보입니다 — 한 줄만 골라 지우거나 이름을 바꾸면 "… 2개 있어 어느 것을 …알 수 없어요" 로 멈춥니다(둘 다 고르면 함께 지워짐, 이름 바꾸기는 풀어서).
> 파일 '보고서' 와 폴더 '보고서/' 가 같이 든 압축은 어느 차례든 폴더 '보고서' + 파일 '보고서 (1)' 로 풀립니다(풀 곳에 원래 있던 파일 '보고서' 는 건드리지 않고 "같은 이름의 파일이나 폴더가 이미 있어…").

## 16. 자동 풀림 EXE 만들기 (35분) — W2-10(+ 검증 지적 수정 1차·2차 줄) · 실기기 확인 필요

자동 시험은 만든 exe 를 **창 없는 무인 모드(/s)로만** 돌려 봤습니다. 두 번 눌렀을 때 뜨는 **창(화면 모드)은 한 번도 띄워 보지 않았습니다** — 아래 줄이 처음 보는 것입니다.

## 21. 인터넷에서 받은 파일 표시(풀기)·7-Zip 라이선스 원문 (15분) — IJ3-03 · 실기기 확인 필요

이번 판부터 **일집 창·탐색기 우클릭으로 푼 파일**에도, 압축 파일에 붙어 있던 '인터넷에서 받은 파일' 표시(Zone.Identifier)를 그대로 붙입니다(사용자 결정).
그래서 메일·웹에서 받은 압축 속 워드·엑셀을 풀어 열면 오피스가 **'제한된 보기'** 로 엽니다. **창 없이 풀기(재사용장치)에는 붙이지 않습니다**(8절 마지막 줄).
자동 테스트는 표시 내용(바이트)·수정 시각·붙이는 파일 범위·설정·실제 exe 의 창 없이 풀기까지 봤고, **진짜 오피스·탐색기·회사 PC 보안 프로그램(DLP)** 은 사람이 봐야 합니다.
준비: **메일(아웃룩)에서 받아 저장한 압축 첨부** 1~2개(워드·엑셀이 든 zip, 있으면 7z·egg). 표시가 붙었는지는 PowerShell 에서
`Get-Content "받은첨부.zip" -Stream Zone.Identifier` → `ZoneId=3` 이 보이면 붙은 것(없으면 웹 브라우저로 받은 압축으로 해 보세요).

## 24. 압축 검사(시험하기)·오류 창·깨진 ZIP 고치기 (25분) — W2-08 → IJ3-02(W2-08 다시) → I4-1(4차) · 실기기 확인 필요

> ZIP 고치기는 원래 목록(끝의 중앙 디렉터리)이 남아 있으면 그 속성·시각을 쓰고, 없으면 각 파일 머리의 값으로 새로 씁니다(폴더 속성·주석은 빠질 수 있음). 일집이 확인할 수 없는 압축 방식(LZMA·PPMd 등)은 내용 확인 없이 그대로 옮깁니다.
> (I4-1 — IJ3-02 의 '찾은 파일 N개' 를 바꿈) 목록이 없거나 믿을 수 없어 원래 파일이 몇 개였는지 모르면 '원래 몇 개였는지 확실하지 않아요 — M개를 살렸어요.' + '…앞에서부터 차례로 확인되는 파일만 살렸어요.'라고 합니다. 파일 맨 앞부터 끝이 데이터로 확인되는 동안만 이어 가고, 멈춘 뒤 다시 찾은 파일 머리는 남은 목록 조각이 그 자리를 가리킬 때만 넣습니다(나머지는 '목록에 없는 조각 K개' — 저장해 담은 문서 속 부품과 가를 수 없어서). 확인할 수 없는 파일(암호를 넣지 않음)은 뒤가 다음 파일 머리로 이어질 때만 그대로 옮기고 '살렸어요' 수에 넣지 않습니다. 목록 모드에서 목록과 파일 머리의 이름이 다르면 어느 쪽이 맞는지 가르지 않고 '이름 정보가 서로 달라요'로 못 살린 파일에 넣습니다.
> 목록이 깨진 ZIP(검증 지적 2차 후): 목록이 중간에서 끊겼거나 목록의 이름·위치가 실제 파일 머리와 맞지 않으면, 시험은 '압축 파일 안의 파일 목록이 손상돼…'로 '문제가 있어요'(+ [ZIP 고치기 시도]), 풀기는 맞는 파일만 풀고 오류로 끝납니다(창 없이 풀기 종료 코드 1). 맞지 않는 파일은 쓰지 않습니다(다른 파일 내용이 그 이름으로 풀리지 않게).

## 25. 압축 속에서 연 파일 — 이름 바꾸기·일집을 먼저 닫을 때 (15분) — I5-A · 실기기 확인 필요

## 26. 풀 때·바꿔 만들 때 원래 파일 지키기·알림 (20분) — I5-B · 실기기 확인 필요

**왜**: 예전에는 ① 같은 이름으로 한 번 더 싼 첨부(`첨부.7z` 안에 `첨부.7z`)를 '여기에 풀기'하고 덮어쓰기를 고르면 **풀고 있는 압축 파일 자신이 안쪽 것으로 바뀌었고**,
② 엑셀로 열어 둔 파일 위에 풀면 나머지 파일도 안 풀고 멈추며 맞지 않는 '관리자 권한으로 다시 시도'를 권했고, ③ 같은 이름 zip 을 [바꾸기]로 만들다 [취소]하면 **예전 zip 까지 없어졌고**,
④ tar 속 링크를 0바이트 파일로 풀면서 '문제없어요'라고 했고, ⑤ 창 없이 풀기에 없는 경로를 주면 창이 떠서 끝나지 않았습니다. I5-B 부터는 모두 원래 파일을 지키고 알립니다.
준비: `일집점검` 에 폴더 `받은 첨부` 를 만들고, 일집(새 판)으로 `본문.txt` 하나를 `첨부.7z` 로 만든 뒤 그 `첨부.7z` 와 `설명.txt` 를 골라 **`받은 첨부` 폴더에 다시 `첨부.7z`** 로 만듭니다(같은 이름 — 메일이 한 번 더 싼 첨부 흉내).
같은 방법으로 `첨부.zip` 도 하나. 엑셀 파일 `견적서 1.xlsx` 와 `메모.txt` 를 든 `보고서.zip` 도 하나 만들어 둡니다.
