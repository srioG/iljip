# 일집 새 버전 손 점검표 (10분 안팎)

일집을 새로 설치하거나 압축 엔진을 바꾼 뒤, 사람이 직접 눌러 보는 점검표입니다.
자동 테스트(`dotnet test`)가 못 보는 **우클릭 메뉴·창·드래그**를 확인합니다. 하나씩 해 보고 □ 에 ✔ 하세요.

---

## 0. 준비 (1분)

1. 바탕화면에 새 폴더 **`일집점검`** 을 만듭니다.
2. `D:\Python\일집\Iljip.Tests\Fixtures\bandizip` 폴더에서 아래 파일을 **복사**해 `일집점검` 에 붙여 넣습니다.
   (원본 폴더에서 바로 하지 마세요 — 원본은 반디집을 지우면 다시 못 만듭니다.)
   - `zip_default.zip` · `zip_zipcrypto.zip` · `7z_default.7z` · `7z_header_encrypted.7z` · `tar_default.tar` · `zip_split.z01`, `zip_split.z02`, `zip_split.zip`(세 개 다)
3. 암호가 필요하면 **`Iljip-Test-1234`** 를 넣습니다(대소문자·하이픈 그대로).

> 아래에서 "지금은 ~ (알려진 문제)" 라고 적힌 것은 이미 알고 있는 문제입니다. 그대로 나오면 정상, **다르게 나오면** 적어 두세요.

## 1. 우클릭 메뉴 (3분)

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | `zip_default.zip` 우클릭 → **일집으로 열기** | 일집 창이 뜨고 왼쪽에 `zip_default.zip` › `일집_샘플` 폴더. 아래 상태줄 **15개 항목** |
| □ | 창에서 `일집_샘플` → `하위폴더` 를 차례로 열기 | `2단계` 폴더와 `보고서 최종.txt` 가 보임. 한글이 깨지지 않음 |
| □ | `zip_default.zip` 우클릭 → **여기에 압축 풀기 (일집)** | 같은 곳에 `zip_default` 폴더가 생기고 그 안에 `일집_샘플` 폴더. `견적서_2026.txt`, `기호 #&+~!'@.txt`, `빈폴더`(빈 폴더)까지 있음 |
| □ | 같은 메뉴를 **한 번 더** | 기존 파일을 덮지 않고 `readme (1).txt` 처럼 `(1)` 이 붙은 파일이 새로 생김 |
| □ | `tar_default.tar` 우클릭 → **압축 풀기... (일집)** → 폴더 고르는 창에서 `일집점검` 선택 | 고른 곳에 `일집_샘플` 폴더가 풀림 |
| □ | `zip_split.zip` 우클릭 → 여기에 압축 풀기 | `분할_샘플` 폴더에 `난수_160KiB.bin`(160 KB)·`설명.txt` 가 풀림 (`.z01`·`.z02` 가 같은 폴더에 있어야 함) |
| □ | 아무 파일 2개 선택 → 우클릭 → **일집으로 압축** | 저장 창(이름 제안) → 압축 옵션 창 → 저장하면 zip 이 생기고 일집 창에 그 zip 이 열림 |

> 폴더 우클릭에는 지금 '일집으로 압축'이 없습니다(알려진 문제 — 설치 설정에서 폴더 항목을 임시로 뺌). `.egg`/`.alz` 우클릭 메뉴도 아직 없습니다.

## 2. 암호 (2분)

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | `zip_zipcrypto.zip`(반디집이 만든 암호 zip) → 여기에 압축 풀기 | 암호 창이 뜸 → `Iljip-Test-1234` → 풀림 |
| □ | 같은 파일을 한 번 더 풀면서 **틀린 암호** `1111` | "비밀번호가 틀린 것 같아요" 로 다시 물음. 취소하면 끝. 풀 곳에 **파일이 생기지 않음** |
| □ | 파일 1개를 일집으로 압축 → 옵션 창에서 암호 **`Test-5678`**(영문) → 저장 | 생긴 zip 을 일집으로 다시 풀면 암호를 묻고, 맞게 넣으면 풀림 |
| □ | 위 zip 을 **반디집 없이** 다시 열기(반디집 지운 PC 또는 다른 PC 의 일집) | 같은 암호로 풀림. (Windows 기본 탐색기는 이 AES 암호 zip 을 못 엶 — 알려진 문제 I2-11) |
| □ | `7z_header_encrypted.7z` 우클릭 → 일집으로 열기 | 지금은 "파일을 열 수 없어요" 오류(알려진 문제 I1-7 — **자동 테스트가 없어 여기서만 확인**). **고쳐지면 암호 창이 뜨고, `Iljip-Test-1234` 를 넣으면 15개 항목이 보여야 함** |

> ⚠ 한글 암호(예: `테스트암호`)는 지금 반디집과 서로 호환되지 않습니다(버그 B3). 거래처에 보낼 암호 zip 은 **영문·숫자 암호**를 쓰세요.

## 6. 알집(EGG·ALZ)·RAR 진짜 파일 (2분) — 자동 테스트가 못 보는 부분

자동 테스트의 EGG/ALZ 는 테스트가 직접 만든 '흉내 파일'이고, RAR 은 픽스처가 아예 없습니다.
**업무 파일 말고**, 알집·WinRAR 이 있는 PC 에서 아무 의미 없는 파일(한글 이름·하위 폴더·빈 폴더·0바이트 파일 포함)로 직접 만든 테스트용 egg/alz/rar 로 확인하세요.

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | 한글 이름 파일·하위 폴더가 든 `.egg` 를 일집으로 열기 | 목록이 보이고 한글이 안 깨짐. 지금 **빈 폴더나 0바이트 파일이 들어 있으면 "파일을 열 수 없어요"가 날 수 있음**(버그 B9 의심 — 나면 적어 두기) |
| □ | 그 `.egg` → 여기에 압축 풀기 | 모든 파일이 풀리고 내용이 열림. 풀린 파일의 **수정한 날짜**가 원래 날짜와 같은지(9시간 어긋나면 적어 두기 — 확인 못 한 위험) |
| □ | 한글 이름이 든 `.alz`(옛 알집 형식)를 열기 | 지금은 한글 이름이 `�` 로 깨질 가능성 큼(버그 B10). 깨지면 적어 두기 |
| □ | 암호 걸린 `.egg` 를 풀기 | 암호 창이 뜸 → 틀린 암호면 다시 물음 → 맞는 암호면 풀림 |
| □ | `.rar` 을 열고 풀기 | 목록·해제가 정상, 한글 이름 안 깨짐 |
