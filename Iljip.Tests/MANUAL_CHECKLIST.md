# 일집 새 버전 손 점검표 (20분 안팎)

일집을 새로 설치하거나 압축 엔진을 바꾼 뒤, 사람이 직접 눌러 보는 점검표입니다.
자동 테스트(`dotnet test`)가 못 보는 **우클릭 메뉴·창·드래그·진짜 알집/WinRAR 파일**을 확인합니다. 하나씩 해 보고 □ 에 ✔ 하세요.
**일집-dist(재사용장치가 쓰는 배포본)를 바꾸기 전에는 적어도 0·2·5·6·8절**을 해 주세요.

## 0. 준비 (1분)

1. 바탕화면에 새 폴더 **`일집점검`** 을 만듭니다.
2. `D:\Python\일집\Iljip.Tests\Fixtures\bandizip` 폴더에서 아래 파일을 **복사**해 `일집점검` 에 붙여 넣습니다.
   (원본 폴더에서 바로 하지 마세요 — 원본은 반디집을 지우면 다시 못 만듭니다.)
   - `zip_default.zip` · `zip_zipcrypto.zip` · `7z_default.7z` · `7z_header_encrypted.7z` · `tar_default.tar` · `zip_split.z01`, `zip_split.z02`, `zip_split.zip`(세 개 다)
   - 한글 암호 확인용: `zip_zipcrypto_korean_pw.zip` · `zip_aes256_korean_pw.zip`
3. 암호가 필요하면 **`Iljip-Test-1234`** 를 넣습니다(대소문자·하이픈 그대로). 이름에 `korean_pw` 가 들어간 파일은 **`테스트암호`**.
4. **새 판으로 확인하세요.** 새 판 실행 파일은 `D:\Python\일집-build\dotnet\Iljip\bin\Release\net8.0-windows\Iljip.exe` 입니다.
   `D:\Python\일집-dist\Iljip.exe` 는 **예전 판**(재사용장치가 쓰는 것 — 8절 확인 전에는 바꾸지 마세요). 셸 확장(우클릭 메뉴)이 예전 판을 부르면 1절 결과가 예전 동작으로 나옵니다.

> 아래에서 "지금은 ~ (알려진 문제)" 라고 적힌 것은 이미 알고 있는 문제입니다. 그대로 나오면 정상, **다르게 나오면** 적어 두세요.

| □ | 같은 큰 파일을 **TAR**(.tar)로 압축하다가 진행 창의 **취소** | 바로 멈추고 상태줄 "압축 취소됨". 쓰다 만 .tar 는 남지 않음. (W1-A 전에는 마지막 큰 파일이면 취소가 안 먹고 '완료' — 버그 B6, 고침) |
| □ | 그 zip 을 풀다가 진행 창의 **취소** | "압축 해제 취소됨". 풀던 큰 파일이 **반쯤 남지 않음**(앞서 다 풀린 파일은 남아도 됨) |
| □ | 그 zip 을 **"이름"\ 에 풀기** 로 풀다가 첫 파일에서 **취소** | 파일이 하나도 안 풀렸으면 빈 이름 폴더도 남지 않음 → 다시 풀면 `(2)` 가 아니라 원래 이름 폴더에 풀림(W1-D 1차 검증) |
| □ | (선택 — 자동 테스트가 이미 확인함) 큰 파일 하나를 **GZ**(.gz)로 압축 → 그 .gz 를 복사해 **뒤쪽을 잘라 낸 것**(받다 만 파일 흉내 — 웹에서 받다가 취소한 .gz 도 됨)을 "이름"\ 에 풀기 | "압축 해제 실패: 이 압축 파일은 손상되었거나 끝까지 받아지지 않았어요(끝부분이 잘려 있어요)…" 오류. 풀 곳에 **절반짜리 파일이 남지 않음**. 암호 창은 안 뜸. (W1-A 1차 검증 전에는 '완료'로 끝나고 절반짜리가 남았음) |

## 6. 알집(EGG·ALZ)·RAR 진짜 파일 (5분) — 자동 테스트가 못 보는 부분

자동 테스트의 EGG/ALZ/RAR 은 테스트가 직접 만든 '흉내 파일'입니다(RAR 은 통합 점검부터 — 압축하지 않은 '저장' 방식만, 반디집이 맞게 푸는 것까지 확인).
**업무 파일 말고**, 알집·WinRAR 이 있는 PC 에서 아무 의미 없는 파일(한글 이름·하위 폴더·빈 폴더·0바이트 파일 포함)로 직접 만든 테스트용 egg/alz/rar 로 확인하세요.

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | 한글 이름 파일·하위 폴더·**빈 폴더·0바이트 파일**이 든 `.egg` 를 일집으로 열기 | 목록이 보이고 한글이 안 깨짐. 빈 폴더·0바이트 파일도 목록에 보임(버그 B9 — 합성 EGG 로만 고침 확인. "파일을 열 수 없어요"가 나면 적어 두기). **빈 폴더가 폴더로**(0바이트 파일이 아니라) 보이는지도 확인 — 일집은 이름 끝 `/` 나 폴더 속성으로 폴더를 알아봄 |
| □ | 그 `.egg` → "이름"\ 에 풀기 | 모든 파일이 풀리고 내용이 열림. 풀린 파일의 **수정한 날짜**가 원래 날짜와 같은지(9시간 어긋나면 적어 두기 — 확인 못 한 위험). "크기가 맞지 않아요"·"내용 확인값(CRC)이 맞지 않아요" 오류가 나면 **멀쩡한 파일인데도 나는 것이므로 꼭 적어 두기**(일집이 새로 하는 내용 확인이 진짜 알집 파일과 어긋난 것) |
| □ | **솔리드**로 압축한 `.egg`(알집 '솔리드 압축' 옵션)와 **분할**(`.vol1.egg`, `.vol2.egg` …) `.egg` 풀기 | 오류 없이 다 풀리고 내용이 열림. (솔리드는 항목별 CRC 가 없어 크기만 확인 — 잘린 솔리드 egg 는 못 알아챌 수 있음) |
| □ | (선택) 위 `.egg` 를 복사해 **뒤쪽을 잘라 낸 것**(받다 만 파일 흉내)을 풀기 | "…을(를) 풀다가 멈췄어요(크기가 맞지 않아요 …). 압축 파일이 손상되었거나 끝까지 받아지지 않은 것 같아요" 오류. 잘린 파일이 짧은 채로 남지 않음(앞서 다 풀린 파일은 남아도 됨). 암호 창은 안 뜸 |
| □ | 한글 이름이 든 `.alz`(옛 알집 형식)를 열고 풀기 | 한글 이름이 바르게 보이고 그 이름으로 풀림(버그 B10 — 합성 ALZ 로만 고침 확인). **한자·기호만 있는 이름**(예: `漢字①.txt`)도 바르게. `�` 로 깨지면 적어 두기(일집이 확인에 실패해 예전 이름을 쓴 것) |
| □ | 손상된 `.egg`(아무 파일 이름을 .egg 로 바꾼 것)를 열어 오류가 난 뒤 **바로 그 파일 지우기** | 오류 창을 닫자마자 지워짐("다른 프로그램이 사용 중" 이 안 뜸 — 버그 B8, 고침) |
| □ | 암호 걸린 `.egg` 를 풀기(영문 암호) | 암호 창이 뜸 → 틀린 암호면 "암호가 맞지 않아요…" 로 다시 물음, 풀 곳에 파일이 남지 않음 → 맞는 암호면 풀림. (옛 ZIP 방식 암호 egg 는 틀린 암호가 검사를 우연히 통과하면 내용 확인값이 틀려 "…(파일이 손상된 경우에도 이렇게 보일 수 있어요)" 로 다시 물음 — 정상. **한글 암호 egg** 는 확인 못 함 — 안 풀리면 적어 두기) |
| □ | `.rar` 을 열고 풀기 | 목록·해제가 정상, 한글 이름 안 깨짐. "손상되었거나 들어 있는 파일이 없어요" 가 멀쩡한 rar 에서 나면 적어 두기 |
| □ | WinRAR 에서 **암호**를 걸어 만든 `.rar`(보통 압축, 영문 암호) → "이름"\ 에 풀기 | 암호 창("암호가 걸린 압축 파일이에요…") → 틀린 암호면 "암호가 맞지 않아요…" 로 다시 물음, 풀 곳에 **쓰레기 파일이 남지 않음** → 맞는 암호면 풀리고 내용이 열림. WinRAR 의 '압축 형식'을 **RAR4** 로 한 것과 **RAR**(RAR5)로 한 것 둘 다. (통합 점검 전에는 RAR4 암호 파일이 암호 창 없이 깨진 파일로 '완료' — 고침) |
| □ | WinRAR '**파일 이름 암호화**'를 켜고 만든 `.rar` → 일집으로 열기 | 열 때 바로 암호 창("파일 이름까지 암호가 걸려 있어요…") → 맞는 암호면 목록이 보이고, 이어서 풀 때 다시 묻지 않음. 틀린 암호면 다시 물음(영어 오류 창이 뜨면 적어 두기) |
| □ | (선택) WinRAR 로 **여러 조각**(`.part1.rar`, `.part2.rar` …)으로 나눈 것 → `.part1.rar` 풀기 | 조각들이 같은 폴더에 있으면 끝까지 풀림 |

## 8. 일집-dist 바꾸기 전 — 재사용장치 egg 해제 (5분) — 통합 점검

재사용장치는 메일로 온 egg·alz 첨부를 `D:\Python\일집-dist\Iljip.exe --extract-to <첨부> <임시폴더>` 로 풉니다(창 없이).
일집-dist 를 새 판으로 바꾸면 **다음 날부터 이 해제가 새 판으로** 바뀌므로, 바꾸기 전에 진짜 egg 몇 개를 새 판으로 풀어 봅니다.
새 판은 egg/alz 의 크기·CRC 를 직접 확인합니다(예전 판은 확인 안 함). 진짜 알집 파일에서 이 확인이 어긋나면 멀쩡한 egg 도 실패로 끝나고
재사용장치가 반디집으로 다시 풉니다(반디집을 지운 PC 라면 해제 실패) — 그래서 이 절이 필요합니다.

1. 최근에 받은 **진짜 egg 첨부 2~3개**(가능하면 한글 이름·하위 폴더가 든 것, 알집으로 만든 것)를 `일집점검` 폴더에 **복사**합니다(원본은 그대로).
2. PowerShell 에 아래를 붙여 넣습니다(첫 줄의 파일 이름만 바꾸세요). 창은 뜨지 않고 끝에 숫자가 나옵니다.
   ```powershell
   $egg = "$env:USERPROFILE\Desktop\일집점검\받은첨부.egg"
   $새판 = "D:\Python\일집-build\dotnet\Iljip\bin\Release\net8.0-windows\Iljip.exe"
   $결과 = "$env:USERPROFILE\Desktop\일집점검\새판_결과"
   (Start-Process $새판 -ArgumentList '--extract-to', "`"$egg`"", "`"$결과`"" -Wait -PassThru).ExitCode
   ```
3. 같은 파일을 예전 판으로도 풀어 비교합니다(예전 판은 실행만 하고 고치지 않습니다).
   ```powershell
   $예전판 = "D:\Python\일집-dist\Iljip.exe"
   $결과2 = "$env:USERPROFILE\Desktop\일집점검\예전판_결과"
   (Start-Process $예전판 -ArgumentList '--extract-to', "`"$egg`"", "`"$결과2`"" -Wait -PassThru).ExitCode
   ```

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | 새 판 숫자 | **0**. `새판_결과` 폴더에 파일이 다 있고 한글 이름이 안 깨짐. 1 이 나오면 그 파일 이름을 적어 두기(바꾸기 전에 알려 주세요) |
| □ | 두 결과 폴더 비교(파일 개수·크기·열어 보기) | 새 판이 예전 판과 같거나 더 많이 풀림(예전 판은 0바이트 파일·폴더가 든 egg 에서 실패하거나 alz 한글 이름이 깨졌음) |
| □ | 알집 **암호** egg 가 있으면 새 판으로(위 2번) | 숫자 **1**(창 없이는 암호를 넣을 수 없음 — 정상). 재사용장치는 이때 반디집으로 넘김(예전과 같음) |
| □ | (바꾼 다음 날) 재사용장치 로그 | '(Iljip으로 .egg 해제)' 다음에 '(Iljip 해제 실패: … → Bandizip 폴백)' 이 예전보다 늘지 않았는지. 늘었으면 그 줄을 적어 두기 |

> 바꾸는 방법·되돌리는 방법은 `D:\Python\일집\HANDOFF.md` '일집-dist 재배포' 절에 있습니다. 재사용장치가 도는 시간에는 바꾸지 마세요.
