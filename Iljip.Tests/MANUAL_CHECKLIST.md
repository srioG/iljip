# 일집 새 버전 손 점검표 (10분 안팎)

일집을 새로 설치하거나 압축 엔진을 바꾼 뒤, 사람이 직접 눌러 보는 점검표입니다.
자동 테스트(`dotnet test`)가 못 보는 **우클릭 메뉴·창·드래그**를 확인합니다. 하나씩 해 보고 □ 에 ✔ 하세요.

---

## 0. 준비 (1분)

1. 바탕화면에 새 폴더 **`일집점검`** 을 만듭니다.
2. `D:\Python\일집\Iljip.Tests\Fixtures\bandizip` 폴더에서 아래 파일을 **복사**해 `일집점검` 에 붙여 넣습니다.
   (원본 폴더에서 바로 하지 마세요 — 원본은 반디집을 지우면 다시 못 만듭니다.)
   - `zip_default.zip` · `zip_zipcrypto.zip` · `7z_default.7z` · `7z_header_encrypted.7z` · `tar_default.tar` · `zip_split.z01`, `zip_split.z02`, `zip_split.zip`(세 개 다)
   - 한글 암호 확인용: `zip_zipcrypto_korean_pw.zip` · `zip_aes256_korean_pw.zip`
3. 암호가 필요하면 **`Iljip-Test-1234`** 를 넣습니다(대소문자·하이픈 그대로). 이름에 `korean_pw` 가 들어간 파일은 **`테스트암호`**.

> 아래에서 "지금은 ~ (알려진 문제)" 라고 적힌 것은 이미 알고 있는 문제입니다. 그대로 나오면 정상, **다르게 나오면** 적어 두세요.

## 2. 암호 (4분)

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | `zip_zipcrypto.zip`(반디집이 만든 암호 zip) → 여기에 압축 풀기 | 암호 창이 뜸("암호가 걸린 압축 파일이에요. 암호를 넣어 주세요.") → `Iljip-Test-1234` → 풀림 |
| □ | 같은 파일을 한 번 더 풀면서 **틀린 암호** `1111` | "암호가 맞지 않아요. 다시 넣어 주세요." 로 다시 물음. 취소하면 끝. 풀 곳에 **파일도 새 폴더도 생기지 않음** |
| □ | 암호 창의 **암호 보이기** 를 켰다 끄기 | 켜면 넣은 글자가 그대로 보이고, 끄면 다시 ●●● 로 가려짐. 어느 쪽에서 고쳐도 같은 암호로 풀림 |
| □ | `zip_zipcrypto_korean_pw.zip`·`zip_aes256_korean_pw.zip`(반디집이 **한글 암호**로 만든 zip) → 여기에 압축 풀기 → `테스트암호` | 둘 다 풀림(예전 버그 B3 — 반디집은 한글 암호를 CP949 로 저장, 고침). 틀린 한글 암호(`테스트암오`)면 다시 물음 |
| □ | 파일 1개를 일집으로 압축 → 옵션 창에서 암호 **`Test-5678`**(영문) → 저장 | 생긴 zip 을 일집으로 다시 풀면 암호를 묻고, 맞게 넣으면 풀림 |
| □ | 위 zip 을 **반디집 없이** 다시 열기(반디집 지운 PC 또는 다른 PC 의 일집) | 같은 암호로 풀림 |
| □ | 옵션 창: 암호 칸에 `1234`(4자) | 오른쪽 안내가 주황색 **"암호가 짧아요 (8자 이상 권장)"** 로 바뀜. 8자 이상이면 회색 "8자 이상을 권장해요". 짧아도 **확인**은 됨(막지 않음) |
| □ | 옵션 창: 두 칸을 다르게(`abcd1234` / `abcd1235`) → 확인 | "비밀번호가 일치하지 않아요." 경고, 창은 그대로 |
| □ | 옵션 창: **암호 보이기** | 두 칸 모두 글자가 보임. 보이는 칸에서 고친 값이 그대로 저장됨 |
| □ | 옵션 창: 암호 방식 **ZipCrypto (호환)** + 영문 암호 → 저장 → 그 zip 을 **Windows 탐색기**로 열기(더블클릭 → 파일 꺼내기) | 탐색기가 암호를 묻고 풀림(AES 는 탐색기가 못 엶 — 그래서 고를 수 있게 함, 예전 I2-11) |
| □ | 옵션 창: 암호 방식 **AES-256** + 한글 암호 `테스트암호` → 확인 | 경고 창 "한글 암호는 다른 프로그램에서 안 풀릴 수 있어요 — 영문·숫자를 권장해요." 와 버튼 3개: ① [영문·숫자로 다시 쓰기] → 옵션 창으로 돌아감 ② [ZipCrypto 방식으로 만들기 …] → ZipCrypto 로 저장됨 ③ [그대로 만들기 (일집에서는 풀려요)] → AES 로 저장됨 |
| □ | ②로 만든 zip 을 **반디집**으로 `테스트암호` 넣고 풀기(반디집 있는 PC) | 풀림(자동 테스트 `BandizipCliTests` 도 bz.exe 로 확인). ③으로 만든 zip 은 반디집에서 "암호가 틀림" 이 정상(그래서 경고함) |
| □ | 옵션 창: ZipCrypto + 이모지 암호(`암호😀`) → 확인 | 경고 창 "…다른 프로그램이 못 읽는 글자(이모지 등)…" 와 [암호 다시 쓰기]·[그대로 만들기 (일집에서는 풀려요)] |
| □ | 옵션 창: **AES-256** + 이모지 암호(`암호😀`) → 확인 | 위와 같은 이모지 경고 창(버튼 2개). 'ZipCrypto 방식으로 만들기 (반디집·알집과 호환)' 버튼은 **안 나와야 함**(이모지는 어느 방식으로도 반디집과 안 맞음 — W1-C 1차 검증 지적) |
| □ | `7z_header_encrypted.7z` 우클릭 → 일집으로 열기 | 지금은 "파일을 열 수 없어요: 파일 이름까지 암호가 걸려 있어요. 암호를 넣어 주세요." 오류(알려진 문제 I1-7 — **자동 테스트가 없어 여기서만 확인**). **고쳐지면 암호 창이 뜨고, `Iljip-Test-1234` 를 넣으면 15개 항목이 보여야 함** |

> 거래처에 보낼 암호 zip 은 여전히 **영문·숫자 암호**가 가장 안전합니다. 한글 암호를 꼭 써야 하면 **ZipCrypto** 로 만드세요(반디집·알집과 맞게 저장 — 알집은 확인 못 함).

## 6. 알집(EGG·ALZ)·RAR 진짜 파일 (2분) — 자동 테스트가 못 보는 부분

자동 테스트의 EGG/ALZ 는 테스트가 직접 만든 '흉내 파일'이고, RAR 은 픽스처가 아예 없습니다.
**업무 파일 말고**, 알집·WinRAR 이 있는 PC 에서 아무 의미 없는 파일(한글 이름·하위 폴더·빈 폴더·0바이트 파일 포함)로 직접 만든 테스트용 egg/alz/rar 로 확인하세요.

| □ | 할 일 | 기대 결과 |
|---|---|---|
| □ | 한글 이름 파일·하위 폴더·**빈 폴더·0바이트 파일**이 든 `.egg` 를 일집으로 열기 | 목록이 보이고 한글이 안 깨짐. 빈 폴더·0바이트 파일도 목록에 보임(버그 B9 — 합성 EGG 로만 고침 확인. "파일을 열 수 없어요"가 나면 적어 두기). **빈 폴더가 폴더로**(0바이트 파일이 아니라) 보이는지도 확인 — 일집은 이름 끝 `/` 나 폴더 속성으로 폴더를 알아봄 |
| □ | 그 `.egg` → 여기에 압축 풀기 | 모든 파일이 풀리고 내용이 열림. 풀린 파일의 **수정한 날짜**가 원래 날짜와 같은지(9시간 어긋나면 적어 두기 — 확인 못 한 위험). "크기가 맞지 않아요"·"내용 확인값(CRC)이 맞지 않아요" 오류가 나면 **멀쩡한 파일인데도 나는 것이므로 꼭 적어 두기**(일집이 새로 하는 내용 확인이 진짜 알집 파일과 어긋난 것) |
| □ | **솔리드**로 압축한 `.egg`(알집 '솔리드 압축' 옵션)와 **분할**(`.vol1.egg`, `.vol2.egg` …) `.egg` 풀기 | 오류 없이 다 풀리고 내용이 열림. (솔리드는 항목별 CRC 가 없어 크기만 확인 — 잘린 솔리드 egg 는 못 알아챌 수 있음) |
| □ | (선택) 위 `.egg` 를 복사해 **뒤쪽을 잘라 낸 것**(받다 만 파일 흉내)을 풀기 | "…을(를) 풀다가 멈췄어요(크기가 맞지 않아요 …). 압축 파일이 손상되었거나 끝까지 받아지지 않은 것 같아요" 오류. 잘린 파일이 짧은 채로 남지 않음(앞서 다 풀린 파일은 남아도 됨). 암호 창은 안 뜸 |
| □ | 한글 이름이 든 `.alz`(옛 알집 형식)를 열고 풀기 | 한글 이름이 바르게 보이고 그 이름으로 풀림(버그 B10 — 합성 ALZ 로만 고침 확인). **한자·기호만 있는 이름**(예: `漢字①.txt`)도 바르게. `�` 로 깨지면 적어 두기(일집이 확인에 실패해 예전 이름을 쓴 것) |
| □ | 손상된 `.egg`(아무 파일 이름을 .egg 로 바꾼 것)를 열어 오류가 난 뒤 **바로 그 파일 지우기** | 오류 창을 닫자마자 지워짐("다른 프로그램이 사용 중" 이 안 뜸 — 버그 B8, 고침) |
| □ | 암호 걸린 `.egg` 를 풀기(영문 암호) | 암호 창이 뜸 → 틀린 암호면 "암호가 맞지 않아요…" 로 다시 물음, 풀 곳에 파일이 남지 않음 → 맞는 암호면 풀림. (옛 ZIP 방식 암호 egg 는 틀린 암호가 검사를 우연히 통과하면 내용 확인값이 틀려 "…(파일이 손상된 경우에도 이렇게 보일 수 있어요)" 로 다시 물음 — 정상. **한글 암호 egg** 는 확인 못 함 — 안 풀리면 적어 두기) |
| □ | `.rar` 을 열고 풀기 | 목록·해제가 정상, 한글 이름 안 깨짐. "손상되었거나 들어 있는 파일이 없어요" 가 멀쩡한 rar 에서 나면 적어 두기 |
